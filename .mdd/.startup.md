## Rules Summary
Read CLAUDE.md for the full rulebook. Key rules for this project:
- TypeScript (strict, no any) for UI/shell; Python (typed, ruff+mypy) for ML backend
- All backend endpoints under /api/v1/
- SQLite via a single shared connection module (StrictDB analog)
- No file > 300 lines, no function > 50 lines
- Never commit .env, HF_TOKEN, model weights, checkpoints, or datasets
- Backbones frozen; only heads trained; training via pluggable job runner
- Always branch off dev — never commit to main
