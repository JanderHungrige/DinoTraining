Admin: test the Store edition

For testers, not for users. This is the Microsoft Store version of V-Rex 0.1.3, signed with a test certificate instead of Microsoft's signature. Regular users download V-Rex from the download page.

1. Download

Test certificate (V-Rex_test.cer) Store edition (V-Rex_0.1.3_x64_test.msix, 26 MB)

Built and tested in the 0.1.3 release run. The certificate's private key existed only during that run, so nothing else can be signed with it.
SHA-256: msix bc2e5666…4e243ec0, cer bd2249dc…00f052f2.

2. Trust the certificate (once per PC)

  1. Double-click V-Rex_test.cer → Install Certificate…
  2. Choose Local Machine → Next, and say Yes to the admin prompt.
  3. Place all certificates in the following store → Browse… → Trusted People (not "Trusted Root") → OK → Next → Finish.

3. Install and start

  1. Double-click V-Rex_0.1.3_x64_test.msix → Install (tick Launch when ready).
  2. Later: Start menu → V-Rex. The installed EXE edition (DinoTraining or V-Rex) can stay; they do not share data.

5. Uninstall

  1. Start menu → right-click V-Rex → Uninstall.
  2. Paste %LOCALAPPDATA%\Packages\JeanQuestEnterprise.V-Rex_f2f23w3rhp35p into the Explorer address bar: it should no longer exist.
  3. Optional, remove the test certificate: Start → certlm.msc → Trusted People → Certificates → delete 522F9C35-….

If something goes wrong

  • "The publisher certificate could not be verified": the certificate went into the wrong store; repeat step 2 with Local Machine and Trusted People.
  • An error in the app: Open the log or Report an issue next to it, or a photo of the screen.
  • The installer refuses: a screenshot of its message.
