Privacy

DinoTraining collects nothing about you. It has no account, no telemetry, no analytics and no advertising. Your pictures, annotations, datasets and models stay on your computer, or in the storage you connect yourself.

What the app downloads, and from where

  • Python and PyTorch, once, at the first start: from GitHub (python-build-standalone), PyPI (pypi.org) and pytorch.org. On Windows, if needed, Microsoft's Visual C++ runtime from aka.ms / microsoft.com.
  • Models you choose to download: from Hugging Face (huggingface.co). Gated models use the access token you enter; it is kept on your computer only.
  • The OSDaR23 example dataset, only if you click it: from the FID move portal (data.fid-move.de).
  • Whether a new version is out, once at each start, for the version from this site (not the Microsoft Store's, which the Store updates): dino.w3rth.de/latest.json, or GitHub if that does not answer. Only the app's version goes along, as part of the request. Turn it off with DINO_UPDATE_CHECK=0.

These servers see your IP address and the files requested, as any download does; their own privacy policies apply.

What goes only where you send it

  • Cloud storage (Amazon S3, Azure Blob Storage, Google Cloud Storage or compatible) that you connect: the app reads your datasets there and writes your annotations back. Keys and secrets are stored on your computer only and never sent anywhere else.
  • MLflow, if you set up a tracking server: training runs are sent to that server.
  • "Report an issue" opens a pre-filled page on GitHub in your browser. Nothing is sent until you submit it there yourself; review the log lines it contains first.

Removing the app

Uninstalling can remove everything stored inside the app. Exports you saved to your own folders or cloud storage are not touched.

Contact: GitHub issues. Last updated: 2026-10-01.

Datenschutz

DinoTraining erhebt nichts über dich. Es gibt kein Konto, keine Telemetrie, keine Analyse und keine Werbung. Deine Bilder, Annotationen, Datensätze und Modelle bleiben auf deinem Rechner oder in dem Speicher, den du selbst verbindest.

Was die App lädt, und woher

  • Python und PyTorch, einmal beim ersten Start: von GitHub (python-build-standalone), PyPI (pypi.org) und pytorch.org. Unter Windows, falls nötig, die Microsoft-Visual-C++-Laufzeit von aka.ms / microsoft.com.
  • Modelle, die du herunterlädst: von Hugging Face (huggingface.co). Geschützte Modelle nutzen das Zugangstoken, das du eingibst; es bleibt nur auf deinem Rechner.
  • Der OSDaR23-Beispieldatensatz, nur wenn du ihn anklickst: vom FID-move-Portal (data.fid-move.de).
  • Ob es eine neue Version gibt, einmal bei jedem Start, für die Version von dieser Seite (nicht die aus dem Microsoft Store, die der Store aktualisiert): dino.w3rth.de/latest.json, oder GitHub, wenn die nicht antwortet. Mit geht nur die Version der App, als Teil der Anfrage. Abschalten mit DINO_UPDATE_CHECK=0.

Diese Server sehen deine IP-Adresse und die angefragten Dateien, wie bei jedem Download; es gelten ihre eigenen Datenschutzerklärungen.

Was nur dorthin geht, wohin du es schickst

  • Cloud-Speicher (Amazon S3, Azure Blob Storage, Google Cloud Storage oder kompatibel), den du verbindest: Die App liest dort deine Datensätze und schreibt deine Annotationen zurück. Schlüssel und Secrets liegen nur auf deinem Rechner und gehen nirgendwo anders hin.
  • MLflow, wenn du einen Tracking-Server einrichtest: Trainingsläufe gehen an diesen Server.
  • „Problem melden“ öffnet eine vorausgefüllte Seite auf GitHub in deinem Browser. Es wird nichts gesendet, bis du sie dort selbst abschickst; prüf vorher die enthaltenen Log-Zeilen.

Die App entfernen

Beim Deinstallieren kann alles entfernt werden, was in der App liegt. Exporte in deinen eigenen Ordnern oder deinem Cloud-Speicher bleiben unberührt.
